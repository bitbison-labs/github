# Security reporting

Report suspected vulnerabilities privately to
[security@bitbison.io](mailto:security@bitbison.io). Do not post vulnerabilities,
channel URLs, submission tokens, or unsanitized capture files in public issues
or pull requests.

Include the affected action commit, runner OS and architecture, a description
of the impact, and reproduction steps using synthetic credentials where
possible. If sensitive evidence is needed, ask for a secure transfer method
before sending it.

If a channel access key or submission token has been exposed, revoke or rotate
it through your Bitbison administrator and remove the exposed logs or files.

This repository contains the GitHub Actions bootstrapper. Reports involving the
downloaded `buildguard`, Bitbison agent, or hosted service can use the same
contact; identify which component is affected.
